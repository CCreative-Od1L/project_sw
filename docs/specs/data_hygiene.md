# 数据卫生规范 · PROJECT_SW

> 安全约束见 [SECURITY.md §7](../SECURITY.md)。

## 1. 内存与日志卫生

- 明文密码、KEK、Master Vault Key、DEK 仅在受控作用域内短生命周期持有。
- 尽可能对敏感缓冲区请求 OS 禁止换出(`mlock` 等效;Flutter 侧通过 libsodium 的安全内存 API 与及时清零),使用后立即清零。
- 应用切后台、锁定、超时自动清零内存中的明文与密钥。
- 日志/埋点严禁输出明文敏感字段;对密码、密钥、条目内容一律脱敏(只可记录条目 id、操作类型、耗时、错误码等非敏感元数据)。
- 剪贴板写入敏感字段须设超时自动清除,并提示用户(详见 §2)。

## 2. 剪贴板卫生(已定)

当前版本:清除超时固定(简化),应用设置中可查看;未来版本开放可配置(已预留)。

| 行为 | 当前固定值 | 未来可选档位(预留) |
|------|-----------|-------------------|
| 剪贴板自动清除超时 | **20 秒** | 10 / 20 / 30 / 60 秒 |

- **覆盖范围**:`password` 与 `custom_fields(secret=true)`(见 [VaultEntry 规格](vault_entry.md))复用同一剪贴板路径与同一清除超时;生成器直接输出(锁定态或解锁态)复制同样走此超时路径。复制非敏感字段(如 username)不触发超时清除。
- **复制提示**:复制敏感字段时只显示一次"已复制到剪贴板"提示;不展示倒计时,清除完成时也不再弹出额外消息。清理仍由独立计时器执行,不依赖提示条生命周期。
- **iOS 通用剪贴板(Handoff)**:复制敏感字段时设 `localOnly`(iOS `UIPasteboard.options.localOnly = true` 等效),禁用跨设备 Handoff 同步。
- **与超时锁定正交**:剪贴板是 OS 级,应用锁定不清零剪贴板;剪贴板清除超时独立计时。两者不冲突。移动平台限制:iOS/Android 应用退后台后进程可能被挂起,应用内 Timer 不保证按秒执行;清除至迟于应用回前台时执行或以 OS 级剪贴板过期选项兜底。
- **设置可见性**:当前固定值须在应用设置中展示(只读),并标注"未来版本可配置"。
